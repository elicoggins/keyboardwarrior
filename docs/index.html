A rhythm typing game in Rust + macroquad, copying off the homework of Clone Hero and YARG.

Type the correct letters in time with the music. Come back with on a computer to try for yourself, and check out the free download to expand your song library.

Notes

Download for free here.

This is only a demo. The game wasn't built for a browser so some sacrifices had to be made to get it running. The downloadable version is the ideal way to play and allows you to easily expand your song library.

Older Macs may show uneven motion in Chrome when chrome://gpu lists OpenGL under GL_RENDERER. If so, use Safari 14.1 or later, or Chrome 129 or later. chrome://gpu should then list ANGLE Metal under GL_RENDERER.
